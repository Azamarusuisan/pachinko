# 現行日本パチンコ調査（物理シミュレーター設計用）

調査日: 2026-08-08

この文書は、公開情報から確認できる現行日本パチンコのうち、本プロジェクトの
物理、盤面、操作、統計、UI設計に影響する事項を整理したものです。「業界の全内部
データ」を意味しません。メーカーのゲージ図、釘の正確な座標、発射初速、材質別の
反発係数など非公開・実測依存の値は、確定値として扱いません。

## 1. 公的に確認できる構造規格

主資料は e-Gov の
[遊技機の認定及び型式の検定等に関する規則](https://laws.e-gov.go.jp/document?lawid=360M50400000004_20240627_506M60400000009)
です。

| 項目 | 公開規格 | 本プロジェクトへの適用 |
|---|---:|---|
| 遊技球直径 | 11 mm | `ball.diameter = 11` は確定基準 |
| 遊技球質量 | 5.4–5.7 g | 既定値5.55 gは範囲中央値 |
| 遊技球材質 | 鋼製、均一材質 | 将来は慣性・接触材質モデルに明記 |
| 発射装置 | 1個 | Launcherは単一装置を基本にする |
| 盤面最大 | 一辺500 mmの正方形を超えない | JSON上限500×500 mmは妥当 |
| 盤面最小包含条件 | 直径300 mmの半円を含められる | 遊技領域そのものを500 mm全面と断定しない |
| 通常入球口入口 | 13 mm以下 | START/Pocketの物理開口を再設計する |
| 開放中の特別入球口 | 90 mm以下 | 将来のアタッカーSchema制約候補 |
| 盤面–ガラス間 | 13 mm超、25 mm以下 | 2Dモデルの成立条件として記録 |
| 釘・風車 | 盤面へ概ね垂直 | Phase 1は正面投影の円Colliderで妥当 |
| 釘・風車軸材質 | 規定硬度の真鍮または同等金属 | restitution/frictionは実測校正値とする |
| 球の視認 | ガラス等が盤面全体の見通しを妨げない | Debug/UIで主要流路を隠さない |

規則は、遊技者が直接操作する場合以外に発射できない構造も要求しています。本作の
AUTOは実機構造の再現ではなく、デジタルシミュレーターの操作補助です。実機準拠モード
と検証用AUTOをUI上で区別します。また、球位置の直接補正・吸引を禁止する本プロジェクト
方針は、遊技結果へ技量が表れなくなる調整を問題とする
[風営法施行規則](https://laws.e-gov.go.jp/law/360M50400000001/20250601_507M60400000010)
の考え方とも整合します。

## 2. 発射と遊技球供給

- 電動式パチンコは最大100発/分の打ち出しが歴史的・現行操作の基準です。
  [SANKYOヒストリー](https://www.sankyo-fever.jp/history/)と
  [日工組の変遷資料](https://nikkoso.jp/history/)の双方で確認できます。
- 100発/分は約600 ms/球です。現在のREALISTIC presetはこの基準に合います。
- 実機発射装置は、発射位置へ供給した球を打球部材/槌、ソレノイド等でレール接線方向へ
  打ち出す構造が一般的です。例として
  [JP2013180077A](https://patents.google.com/patent/JP2013180077A/en)があります。
- 発射強度は飛距離を変える一方、公開一次資料から一般化できる「標準初速」は確認できて
  いません。現在の最大5.2 m/sは実測確定値ではなく校正パラメータです。
- 発射間隔、打球強度、打ち出し角度、発射レール接触、球止め周辺の減速を独立パラメータ
  として保持すべきです。

## 3. 現代的な盤面の機能構成

[SANKYOのパーツ名称資料](https://www.sankyo-fever.jp/beginner/useful-information/7/)
および[釘の説明](https://www.sankyo-fever.jp/beginner/qa/pachinko/134/)から、少なくとも
次の物理/表示要素を区別します。

1. 外周ガイドレールと発射レーン
2. 遊技領域、障害釘、天釘、寄り釘
3. 中央液晶・センター役物を避ける左右流路
4. 風車
5. ワープ入口とステージ
6. 袴釘、ジャンプ釘、命釘
7. スタートチャッカー（ヘソ）
8. 普図ゲート/スルーチャッカー
9. 普通電動役物（電チュー）
10. 大入賞口（アタッカー）
11. 一般/他入賞口
12. 下部OUT口

大当り時は左打ちを維持する機種と、画面/音声の指示で右打ちへ切り替える機種が
あります。[SANKYOの遊技説明](https://www.sankyo-fever.jp/beginner/how-to-play/7/)
で確認できます。したがって将来のBoard Schemaには `recommendedRoute: LEFT | RIGHT` と、
左/右それぞれの発射強度帯を持たせます。

メーカー工場例では1台に約130本の釘を使用しています。
[SANKYO工場資料](https://www.sankyo-fever.jp/research/21/)
これは全機種共通の規格値ではありませんが、90本の現プロトタイプが現代デジパチの
視覚密度として不足している可能性を示します。釘数は130本へ機械的に合わせず、参照画像
から座標を抽出してグループ別に校正します。

## 4. 盤面寸法と座標モデル

- 法定上限は500×500 mmです。
- 特許文献には遊技領域を直径約380 mmと記述する例があります
  ([JP2003175172A](https://patents.google.com/patent/JP2003175172A/ja))。これは全現行機の
  統一寸法ではなく参考値です。
- Physics Boardを500×500 mmの定義域に保ちつつ、実際に玉が流れる領域は円弧状レールで
  およそ380–420 mm級に制限する設計が妥当です。
- 正確な有効遊技領域、レール曲率、ガラス距離、釘頭径、釘突出長は、対象実機の正面画像、
  スケール基準、可能なら実物測定で確定します。

## 5. 現行機のゲームスペックの幅

物理入賞と抽選は分離します。現在のメーカー公開例では、通常時大当り確率は約1/79.9、
1/99.9、1/155.2、1/319.6など複数帯があり、ヘソ賞球も1個または3個など機種により異なり
ます。大入賞口は7、8、15個等、RUSH/ST/転落/時短/LTといったゲームロジックも多様です。

例:

- [SANYO 2026年機種資料](https://www.sanyobussan.co.jp/information/pdf/sanyo_press_release_20260220_1.pdf): 通常約1/319.6、ヘソ等1個、大入賞口15個
- [SANYO 2025年機種資料](https://www.sanyobussan.co.jp/information/pdf/sanyo_press_release_20250711_2.pdf): 約1/319.6、ヘソ3個、大入賞口15個
- [SANYO 2025年機種資料](https://www.sanyobussan.co.jp/information/pdf/sanyo_press_release_20251023.pdf): 約1/79.9、ヘソ3個、大入賞口7個

これらは `physics-core` ではなく将来の `game-logic` / `machine-spec` データに置きます。
「STARTに入った」という物理イベントだけを抽選入力にし、抽選結果による軌道補正は行いません。

## 6. P新世紀エヴァンゲリオン15を参考にする範囲

[SANKYO公式機種資料](https://www.sankyo-fever.jp/collection/925/)で確認できるのは、
BIG IMPACT筐体、中央スマートハンドル、右側大型ギミック、IMPACTレバー、ST163回、
時短100回等です。公式資料は正確な釘座標やゲージ寸法を公開していません。

本プロジェクトで参考にしてよい範囲:

- 大型中央液晶の周囲を流れる通常時の左流路
- 上部から左側、風車、袴、ヘソ、OUTへ至るゲージの構成
- スマートハンドルを意識した操作配置
- 右打ち用の別流路を将来追加できる構造

参考にしない/複製しない範囲:

- 公式キャラクター、ロゴ、映像、音声、筐体意匠の複製
- 画像から検証せず推測した釘位置を「実機値」と表記すること
- 実機抽選ロジックの無断複製

## 7. スマパチと現在の市場

日工組は、スマパチを遊技球数を電磁的方法で記録・表示できるぱちんこ遊技機として扱って
います。物理盤内では封入球が循環しても、UI上の持ち球は数値表示になります。
[スマパチの案内](https://nikkoso.jp/smart_pachinko/)を参照。

警察庁の2025年（令和7年）統計では、ぱちんこ屋等の営業所は6,464、ぱちんこ遊技機は
1,872,041台、回胴式は1,362,177台、合計3,234,357台です。
[警察庁公表資料](https://www.npa.go.jp/news/release/2026/080423huzokukankeitoukei.pdf)
によります。これはUI/物理定数ではありませんが、スマート機を含む現行市場の背景データです。

## 8. 777Realから参考にする範囲

[777Real公式FAQ](https://faq.777real.net/hc/ja/articles/22217934262297-%E9%81%8A%E3%81%B3%E6%96%B9)
では、画面下部の「オート」でON/OFFを切り替え、一部機種でハンドル調整を行う操作が確認
できます。参考にするのは次の情報設計です。

- 台を主表示とし、操作を下部へ集約
- オート状態を明確に表示
- ハンドル強度をプレイ中に調整
- 総回転、大当り、差玉、所持球等のデータを盤面外に表示
- スマートフォンで片手操作しやすい固定操作領域

777Real固有の画面、アイコン、通貨、ロゴ、資産、配色はコピーしません。

## 9. 現行実装とのGap

| Gap | 現在 | 必要な対応 |
|---|---|---|
| 遊技領域 | 500 mm全面に近い表現 | 約380–420 mm円弧領域へ再設計 |
| レール | 直線segment中心 | 円弧を細分化した連続レール/curve schema |
| 釘数 | 90本 | 画像抽出後に密度を再評価。目安130前後は参考値のみ |
| 風車 | 釘群のみ | 回転可能な専用Mechanism/Collider |
| 中央役物 | 見た目のみ | 実際に玉を遮る固定Collider輪郭 |
| ワープ/ステージ | なし | 入口sensor、通路、ステージrailを追加 |
| ヘソ開口 | sensor 26 mm幅 | 13 mm以下の実開口と命釘を物理的に構築 |
| OUT | 横長sensor | 下部回収口へ流すレールと狭いOUT口 |
| 発射 | 単一velocity | 打球、レール接触、球止めを分離校正 |
| UI | 開発ツール主体 | 通常遊技HUDと開発パネルをモード分離 |
| AUTO表現 | 通常操作扱い | DIGITAL AUTO / 実機準拠モードを明示 |
| 右打ち | 未実装 | 独立右ルートと推奨打ち分け状態を追加 |

## 10. 測定しなければ確定できない値

次は公開資料だけで正確に決めません。

- エヴァ15の全釘座標、釘頭径、釘間隔、釘角度
- 外周/内周レールの正確な曲率と反発特性
- 発射powerごとの初速分布、角度分布、回転量
- 球–釘、球–樹脂、球–レールの動摩擦/静摩擦/反発係数
- 盤面傾斜、ガラスとの接触頻度、空気抵抗の実効値
- 風車の慣性、軸摩擦、羽根形状
- ワープとステージの奥行きを2Dへ射影するモデル

これらは `source: MEASURED | OFFICIAL | PATENT_REFERENCE | IMAGE_ESTIMATE | CALIBRATED`
と信頼度をBoard metadataへ付け、実機動画の追跡または寸法入り正面画像で校正します。

## 11. 次の実装順序

1. Board Schemaへ円弧レール、部品種別、source/confidence metadataを追加
2. 実機画像校正用に4点射影と11 mm球スケール測定ツールを作る
3. 500 mm座標域内へ約400 mm級の円形遊技領域を作り直す
4. 中央役物、ワープ、ステージ、風車、袴、13 mm以下のSTART、OUTを物理化
5. 発射レールを曲線化し、発射初速を測定可能なテストコースを作る
6. 100/1000/10000発を再実行し、旧Goldenとは別versionで基準を作る
7. 通常遊技UIとPhysics Lab UIを分離する

## 12. 2026-08-10 物理寸法の追加調査

確認済みの一次・準一次資料:

- e-Gov別表第4: 玉11 mm、5.4–5.7 g、鋼製、100球/分以下、盤面500 mm角以内、
  盤–ガラス間隔は13 mm超25 mm以下。
- 日本ベアリング工業会『ベアリング』47巻1号: 代表製品は11.0±0.007 mm、
  5.45±0.01 g、真球度約5 µm、表面粗さ約0.2 µm Ra。
  <https://www.jbia.or.jp/about/illust/pdf/pachinkodama.pdf>
- `JP4913910B1`: 釘軸径1.8–1.9 mm、実施例1.835 mm、頭径約4 mm。
  <https://patents.google.com/patent/JP4913910B1/ja>
- 特許庁『遊技機及びその関連技術』: 釘は盤面から約17.5 mm露出し、風車は玉の
  衝突で回って左右へ振り分ける。<https://dl.ndl.go.jp/pid/1249341>
- `JP4536466B2`: 盤・ガラス・釘・役物・レールを衝突対象とし、設置角、発射ばらつき、
  材質別摩擦/反発、角速度を扱うシミュレーション先行例。
  <https://patents.google.com/patent/JP4536466B2/ja>

この根拠から、正面2Dの釘Colliderは頭径4 mmではなく軸径相当の半径0.92 mmを採用した。
球質量は代表製品値5.45 g、回転慣性は固体球の `2/5 mr²` とした。ただし球–釘、金属
レール、ゴム、樹脂、ガラス、盤面の摩擦・反発係数と発射初速は公開実測値がないため、
現状値は引き続き仮説である。

## 13. 2Dモデルの限界と校正条件

実機では球径11 mmに対し奥行き方向へ2–14 mm超の中心移動余地があり、盤面のネカセは
主に板/ガラス接触と三軸回転へ作用する。重力scaleをわずかに下げるだけでは再現できない。
実機一致を判定するには、レール出口の位置・速度・角速度分布、実測釘座標、盤傾斜、
ガラス間隔、1,000fps以上の単一衝突映像、受動風車の質量/減衰、START/OUTログが必要。

短い単一衝突区間は反射角・速度保持率・回転で比較し、多衝突後は個別軌跡ではなく
route、滞在時間、衝突数、heatmap、terminal率の分布で比較する。START率だけに合わせて
摩擦や釘座標を変更してはならない。
